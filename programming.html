Here's some of my programming projects!

Most AI detection tools are online services, which often comes with privacy concerns. To address this, I decided to write a local-first AI detection tool that uses a small (~2B parameters) LLM to analyze text. It compares the output from the LLM to the input text and outputs a similarity. If the similarity is too high, it classifies it as AI text. In testing, I was able to achieve 95% accuracy.

I've been using Linux instead of Windows for a while now, and to help me better understand Linux, I decided to write a helper script for the arch linux package manager, pacman. Pacman already has a number of helper scripts and wrappers that automate the process of installing packages manually from the user uploaded repository (AUR), but I wanted to gain a better understanding of Linux and I also felt that some of those existing solutions were overkill. One of the challenges of installing a package manually from the AUR is if the package depends on another package from AUR, which must then be manually installed too. This loop of dependencies needing manual installation can get quite annoying in some cases. This script fixed that issue and added some other quality of life features.

Another Linux project I worked on was an automatic post-installation setup script. After having to reinstall my system multiple times to fix issues, I decided to create a script that would install apps, change settings, and download files from a backup server.

Back when I was in highschool, my school used a grading system called Skyward. I built a Chrome extension to improve the Skyward user interface. I engineered several key features, including a GPA calculator and a way to track grades over time. Beyond the initial development, I managed the deployment and user base, growing the extension to over 100 active users, and bringing other team members on to develop other features such as a dark theme. This role required me to act as both a developer and provide technical assistance to users, iterating the extension based on direct feedback.
